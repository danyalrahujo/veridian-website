# Veridian – Enterprise AI & Data Analytics Website

🌐 **Live Demo:** https://danyalrahujo.github.io/veridian-website/

## Overview

Veridian is a modern, enterprise-inspired website prototype for an AI, Machine Learning, and Data Analytics consulting company. The project showcases a premium user interface, clean information architecture, and responsive design tailored for organizations providing enterprise AI and digital transformation services.

The website is designed to reflect the visual quality and user experience of leading technology consulting firms while serving as a foundation for future development using modern web technologies.

---

## Features

- Modern enterprise landing page
- Responsive design for desktop and mobile
- Sticky navigation with mega menus
- Animated hero section
- Company overview and key metrics
- Services showcase
- Industry-specific solutions
- Business solutions section
- Delivery process timeline
- Case studies
- Client testimonials
- Call-to-action section
- Professional footer
- Smooth animations and scroll effects
- Dark mode demonstration
- Accessible and SEO-friendly structure

---

## Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript
- SVG Animations
- Intersection Observer API
- Responsive Design
- Google Fonts (Inter & Space Grotesk)
